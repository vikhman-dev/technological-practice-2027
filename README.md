## Проверки

Успешно выполнена 71 проверка: 10 тестов unittest, 18 тестов Django и 43 проверки JavaScript и DOM в jsdom. Проверки DOM не заменяют оценку геометрии экрана и совместимости реальных браузеров. Дополнительный сценарий для Chromium включён в проект отдельно.

Тестовый клиент Django выполнил две последовательные серии по 200 GET после 20 запросов прогрева. Размеры SQLite-баз — 101 и 10001 запись. Протокол измерений, методика и ограничения содержатся в `evidence/benchmark.json` и `evidence/README.md` полного проекта.
